# WinDynamicNotch

Медиавиджет в стиле Dynamic Island для Windows: компактная панель сверху по центру экрана
показывает текущий трек и обложку, а по клику раскрывается в карточку с крупной обложкой 1:1,
управлением воспроизведением и перемоткой.

## Возможности

- Панель скрыта по умолчанию: появляется при наведении курсора в зону сверху по центру экрана
  (полоса ~360×26 DIP). Появление — «из камеры»: по центру верхней кромки включается кружок,
  который растягивается в панель, а содержимое проявляется следом. При уходе курсора всё
  стягивается обратно в кружок. Перед появлением есть задержка ~420 мс, поэтому окно можно
  спокойно перетащить к верхней кромке — панель не выскочит. Пока зажата кнопка мыши,
  появление заблокировано полностью.
- Медиаклавиши (play/pause, next, prev, stop) показывают панель на ~3 секунды, не перехватывая
  сами клавиши: команда всё так же уходит в плеер.
- Уходит сама, когда курсор уходит с панели, — окно при этом становится «прозрачным» для кликов.
- Компактная панель: обложка, название трека, исполнитель и три кнопки —
  «предыдущий / play-pause / следующий».
- Раскрытая карточка: обложка 1:1, название, исполнитель, таймлайн с перемоткой, кнопки
  «предыдущий / play-pause / следующий». Раскрытие — пружинная анимация высоты плюс
  последовательное появление обложки, текста, таймлайна и кнопок.
- Данные берутся из системного SMTC (`GlobalSystemMediaTransportControlsSessionManager`),
  поэтому работают с любым плеером, который публикует медиасессию: Spotify, Media Player,
  браузеры (YouTube, SoundCloud и т.д.), VLC и другие.
- После смены трека обложка до-опрашивается несколько секунд (0.25/0.7/1.5/2.5/4/6 с):
  Windows часто отдаёт новое название раньше новой картинки, иначе обложка «отставала» на трек.
- Автоматическое сворачивание через 8 секунд бездействия.
- Иконка в трее: показать/скрыть панель, автозапуск с Windows, выход.
- Панель не появляется на панели задач и в Alt+Tab, не забирает фокус у активного окна.

## Требования

- Windows 10 1809+ или Windows 11.
- .NET 9 SDK для сборки (или .NET 9 Desktop Runtime для запуска готовой сборки).

## Установка

Готовый установщик: `dist\WinDynamicNotch-Setup-<версия>.exe` (~72 МБ). Внутри — self-contained
сборка, поэтому .NET на машине пользователя не нужен: скачал, запустил, работает.

Что делает установщик:

- ставит приложение в `%LOCALAPPDATA%\Programs\WinDynamicNotch` — без запроса прав администратора;
  в диалоге можно выбрать установку для всех пользователей (тогда понадобится UAC);
- создаёт ярлык в меню «Пуск», по желанию — на рабочем столе;
- по желанию включает автозапуск при входе в Windows (тот же ключ реестра, что переключается из трея);
- закрывает уже запущенный экземпляр перед установкой/удалением, иначе exe занят;
- удаляется через «Параметры → Приложения» (или `unins000.exe`) вместе с `%LOCALAPPDATA%\WinDynamicNotch`.

Установщик не подписан сертификатом, поэтому SmartScreen может показать «Неизвестный издатель»:
«Подробнее» → «Выполнить в любом случае».

## Сборка и запуск

```powershell
dotnet build -c Release
dotnet run -c Release
```

Готовый exe:

```
bin\Release\net9.0-windows10.0.19041.0\WinDynamicNotch.exe
```

Один файл без установленного рантайма:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Результат — `bin\Release\net9.0-windows10.0.19041.0\win-x64\publish\WinDynamicNotch.exe`.

### Сборка установщика

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer\build-installer.ps1
```

Скрипт делает self-contained publish в `publish\`, затем собирает установщик в `dist\`.
Нужен Inno Setup 6 (`winget install JRSoftware.InnoSetup`). Версия установщика берётся
из `<Version>` в `WinDynamicNotch.csproj`. Иконка приложения (`Assets\app.ico`) генерируется
скриптом `installer\make-icon.ps1`.

## Управление

| Действие | Результат |
|---|---|
| Наведение в верхнюю центральную зону экрана (~420 мс) | панель появляется |
| Медиаклавиша на клавиатуре | панель появляется на ~3 с |
| Уход курсора с панели | панель скрывается |
| Клик по компактной панели (кроме кнопок) | раскрыть карточку |
| Кнопки ‹ / ⏯ / › на компактной панели | предыдущий трек / play-pause / следующий |
| Кнопка «шеврон» в карточке | свернуть |
| Клик по шкале | перемотка на позицию |
| Перетаскивание ползунка | перемотка |
| Двойной клик по иконке в трее | показать / скрыть панель |
| ПКМ по иконке в трее | автозапуск, выход |

## Ограничения

- Название, исполнитель, обложка и таймлайн зависят от плеера: не все приложения публикуют
  обложку и поддерживают перемотку через SMTC. Если плеер не поддерживает seek, шкала
  отображается неактивной.
- Панель закреплена сверху по центру основного монитора; зона появления задаётся константами
  `HotZoneHalfWidth` / `HotZoneHeight` в `MainWindow.xaml.cs`.

## Структура

```
App.xaml(.cs)                 запуск, трей, единственный экземпляр
MainWindow.xaml(.cs)          интерфейс, появление по наведению, анимации
Services/MediaSessionService  работа с SMTC: трек, обложка, таймлайн, команды
Interop/NativeMethods         Win32: стили окна, cursor hit-test, монитор
Interop/KeyboardHook          глобальный хук медиаклавиш
Tray/TrayIconManager          иконка в трее и автозапуск
Assets/app.ico                иконка приложения и трея
installer/                    сборка установщика (Inno Setup) и генерация иконки
```
